WorkAdventu

An open virtual world — explore, collaborate, and play together

View on GitHub Documentation

Features

🌍

Virtual Worlds

Build and explore custom virtual spaces with tile-based maps designed for interaction.

🎮

Real-time Multiplayer

Move your avatar, meet others, and trigger video/audio conversations by walking up to people.

🔗

Integrations

Embed websites, trigger scripts, and connect external services directly from within the world.

🛠️

Open Source

Fully open source and self-hostable. Customize every aspect to fit your community or workspace.

Getting Started

  1. Clone the repository: git clone https://github.com/gfeller/workadventu.git
  2. Install dependencies and set up the project as described in the README.
  3. Configure your maps and launch the server.
  4. Share the link with your team and start adventuring!
